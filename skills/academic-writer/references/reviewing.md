# Workflow: Reviewing and Revising Others' Drafts

## Pick the mode first

- **Feedback mode** — the author revises; output is a review report.
  Default for students' drafts (the learning is in the revising).
- **Revision mode** — the user edits as co-author; output is the edited
  draft plus a change log and open questions for the other authors.

Ask if not stated. The outputs differ completely.

## Pass 1: Big picture (before any line edits)

Read the whole draft, report only:

1. **The contribution in one sentence.** If you can't produce it, that's
   finding #1.
2. **The storyline** — problem → gap → idea → evidence → conclusion.
   Which links are weak, missing, or buried under side material?
3. **Fatal issues** — unsupported central claims, missing baselines,
   methodological errors, overclaimed conclusions. Verify what you can;
   mark the rest `[AUTHOR TO VERIFY]`.

Don't line-edit yet — polishing prose in a section that needs restructuring
wastes everyone's time.

## Pass 2: Section by section

Judge each section by its role in the storyline: does it do its job, is the
evidence adequate, is anything essential missing (reproducibility,
comparisons, limitations)? Flag suspect references for verification —
never invent replacements.

## Pass 3: Language (only if asked, or in revision mode)

Fix representative instances and *name the pattern* rather than silently
rewriting everything — the author should learn it. Change technical terms
only when wrong, and say so.

## Output

**Feedback mode** → a review report: short summary; major comments ordered
by importance (each with location, why it matters, what would resolve it);
minor comments; and a private verdict for the user on how close the draft
is to submittable. Tone: direct but constructive — criticize the text,
never the author.

**Revision mode** → the edited draft (respecting the project's format and
collaboration conventions), a change log with reasons, and questions for
the authors marked `[AUTHOR TO VERIFY]` in the text.

## Journal revisions

For a response to reviewers: quote every referee comment verbatim, respond
directly beneath it, and point to the exact change in the manuscript. No
comment goes unanswered. If a referee misunderstood, treat it as a clarity
failure of the text and fix the text.
